## Introdukzioa
Taxi's janari azkarra eskatzeko erabiltzen den programa bat da. Non pizzak eta hanburgesak eskatu ahal dituzu, hanburgesak McDonald's-en eta BurgerKing-en eta pizzak Telepizza-n eta Pizza Hut-en.

Aplikazioaren barruan hurrengo gauzak egin ditzakezu: 
<ol>
  <li>Eskaera sortu / Eskaerarekin jarraitu</li> 
  <li>Eskaera ezabatu</li>
  <li>Eskaera ikusi</li>
  <li>Datuak ikusi / Datuak eguneratu</li>
  <li>Eskaera bukatu</li>
  <li>Aplikazioatik irten</li>
</ol>

Programa hau C#-en garatuta dago.

## Erabilpena
Aplikazio nahiko sinplea da, eskaera egiteko bakarrik zehaztu behar duzu pizza edo hanburgesa nahi duzun, eta ondoren edaria eta postrea eskatuko dizu.

Berezitasun bakarra **Pizza Hut**-en dago, bertan pizza pertsonalizatu dezakezu gutxienez 3 osagairekin.

Eskaera bukatzerakoan zure datuak zehazteko eskatuko du, hori egin eta gero eskaera berrituko da eta eskaera berri bat egin nahi duzun galdetuko du.

Aplikazio hau erabili nahi baduzu bakarrik deskargatu egin beharko duzu eta beharrezko extentsioak eta konpiladoreak.
